# Risk Register — FNOL Claims-Triage Copilot

**AC-11 · SPEC-10 §2.1.** Every mitigation cites a committed control. Every evidence cell points at
an artifact produced by committed code: a log record, a report, a trace span, or a test.
`scripts/verify_citations.py` resolves every path, `::symbol`, `#L` line, guard rule id and
run/span id in this file (Rule R2).

Categories use the **OWASP Top 10 for LLM Applications** (v1.1 numbering, as in SPEC-10: LLM01 Prompt
Injection, LLM02 Insecure Output Handling, LLM04 Model Denial of Service, LLM06 Sensitive Information
Disclosure, LLM07 Insecure Plugin Design, LLM08 Excessive Agency, LLM09 Overreliance) and the
**NIST AI RMF** functions (GOVERN / MAP / MEASURE / MANAGE). L / M / H = low / medium / high.
